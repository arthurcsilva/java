# Java

Repositório dedicado aos meus estudos de **Java**, reunindo exercícios, desafios, projetos de prática e anotações desenvolvidos ao longo da minha formação como desenvolvedor.

O objetivo deste repositório é registrar minha evolução na linguagem, consolidar fundamentos de programação e construir uma base sólida para o desenvolvimento **Back-end com Java**.

## 🚀 Projeto pessoal — Portal Fiscal

Como projeto de longo prazo, pretendo desenvolver o Portal Fiscal, uma aplicação voltada à apresentação de resultados fiscais para gestores e diretoria, além do controle de prazos, guias e outras atividades da área fiscal.

O projeto será desenvolvido em diferentes versões, acompanhando minha evolução nos estudos e permitindo aplicar na prática os conhecimentos adquiridos ao longo da formação.

### Beecrowd

Os exercícios da plataforma [beecrowd](https://www.beecrowd.com.br/) estão organizados dentro de `exercises/beecrowd/`, mantendo as categorias utilizadas pela própria plataforma.

Atualmente estão contempladas as categorias:

* `sequential`
* `selection`
* `repetition`
* `array`

### Programação Orientada a Objetos

Os exercícios e pequenos projetos de POO ficam em `exercises/oop/`.

Entre eles:

* **Gestão de Frota** — prática de classes, atributos, métodos e construtores.
* **Tech Library** — prática de modelagem de objetos e operações de empréstimo e devolução.
* **Turos Bank** — prática de modelagem de contas, depósitos, saques e regras de negócio.

## 🎯 Objetivo

Construir, de forma progressiva, uma base sólida em Java que permita avançar para o desenvolvimento de aplicações reais, APIs e sistemas Back-end.

Este repositório representa meu processo de aprendizado e evolução. Por isso, o código pode apresentar diferentes níveis de maturidade conforme novos conceitos são estudados e praticados.
